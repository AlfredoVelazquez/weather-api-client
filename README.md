# Weather API Client

Aplicación desarrollada en Python para consultar información del clima utilizando una API pública.

---

## Objetivo del proyecto

Este proyecto tiene como finalidad aprender y practicar:

- Consumo de APIs REST
- Uso de requests en Python
- Manejo de respuestas JSON
- Validaciones
- Manejo de errores
- Buenas prácticas
- Git y GitHub
- Estructura profesional de proyectos Python

---

## Funcionalidades planeadas

- Consultar clima por ciudad
- Obtener temperatura
- Obtener humedad
- Mostrar descripción del clima
- Mostrar pronóstico básico
- Validar errores de búsqueda

---

## Tecnologías utilizadas

- Python
- Requests
- Git
- GitHub
